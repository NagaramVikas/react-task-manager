# React Task Manager

A beginner-friendly React project demonstrating component state, event handling, conditional rendering, list rendering, and browser localStorage.

## Features

- Add tasks
- Mark tasks as completed
- Filter All / Active / Completed
- Delete tasks
- Persists tasks with localStorage
- Responsive UI

## Tech Stack

- React
- JavaScript
- Vite
- HTML
- CSS
- Browser localStorage

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Project highlights

The main React concepts used are `useState`, `useEffect`, form handling, array methods (`map` and `filter`), conditional rendering, and localStorage.
